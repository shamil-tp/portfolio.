Rewind

Self-Hosted Music Server

Project Overview

Rewind is a lightweight, self-hosted music server for music you own. Plug a USB drive full of music into a home server, point Rewind at it, and listen in a browser on the server, across the home network, or over a private Tailscale network.

It needs no accounts with anyone, no cloud service and no telemetry. The whole thing ships as one Go binary with the web interface built in and one SQLite file — no Node.js, database server or Docker on the server.

How The Project Works

Rewind is a single Go process that indexes music folders into SQLite and serves both the API and an embedded Svelte web player. It is private by default and only becomes reachable from other devices when the owner turns that on.

1
Install — a verified release archive is installed as a systemd service running as an unprivileged user with a read-only file system, except for its data directory.
2
Claim the server — the owner account is created only from the server itself (via an SSH tunnel) using a one-time setup code. There is no default password.
3
Index the library — Rewind scans the configured folders for MP3, FLAC, M4A, Ogg and WAV files, reads tags with TagLib, and never writes to the music. Rescans are incremental, and unplugging the drive keeps the library and playlists.
4
Stream — the browser plays the original files with seeking via HTTP Range requests; nothing is transcoded. Files are served only through an indexed track's database record, only from inside its folder, and never through symlinks.
5
Listen anywhere private — optional LAN access or HTTPS through tailscale serve. Rewind never opens firewall ports and is never exposed to the internet.
6
Operate — the installer upgrades by verifying the archive, test-starting it, backing up the database, switching and health-checking, and can roll back to any earlier version.

Key Features

  • Your Files Stay Put: Indexes MP3, FLAC, M4A (AAC/ALAC), Ogg and WAV from one or more folders, read-only.
  • Incremental Rescans: Only changed files are re-read; a disconnected drive keeps its library and playlists.
  • Web Player: Browse, search and sort the library, with a floating mini player and a full Now Playing screen.
  • No Transcoding: Streams the original files with seeking over HTTP Range.
  • Playlists & Preferences: Ordered playlists with previous/next, and per-account preferences.
  • Themes: Rewind Dark (neo-brutalist), Light, OLED Black, and custom colours with contrast checks and live preview.
  • Installable PWA: Only the interface is cached — music, library data and sign-in never stay on the device.
  • Private by Default: Listens on 127.0.0.1 only, one owner account, no default password.
  • Tiny Footprint: One Go binary and one SQLite file.
  • Optional Plugins: Compiled-in plugins the administrator must enable, such as a missing-tracks report.
